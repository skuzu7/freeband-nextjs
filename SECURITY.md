# Security Policy

## Scope

This repository and maintainer-controlled local or staging deployments are in
scope for defensive review. Production testing requires the deployment owner's
explicit authorization. Third-party services, user accounts, and infrastructure
are out of scope unless separately authorized.

## Reporting

Do not include credentials, personal data, or working exploit payloads in a
public issue. Use GitHub private vulnerability reporting when available, or
contact the maintainer through the LinkedIn profile linked from
[github.com/skuzu7](https://github.com/skuzu7).

## Maintainer response

Reports are reproduced against a local or staging instance, documented with the
minimum necessary data, fixed in source, and verified with the repository's
test, lint, type-check, build, and dependency-audit commands.
